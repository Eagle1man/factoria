# DESIGN.chat.md — чат с агентами и трассы

Переопределяет §2–§3 `DESIGN.md` для маршрутов `/agents` и `/agents/:id/trace`.
Сетка, компоненты и запреты (§4–§9) действуют без изменений.

Почему отдельный файл: это единственный светлый экран. Здесь читают текст,
а не числа, и важно мгновенно отличать, **кто говорит** — человек, агент или
система, и **на основании чего** агент сделал вывод.

## 1. Отличия от базовой темы

| Параметр | База | Чат | Причина |
|---|---|---|---|
| Фон | тёмный | **светлый** `#F7F8FA` | длительное чтение текста |
| Ширина колонки сообщения | — | **720 px** | комфортная строка ~75 символов |
| Интерлиньяж текста | 20 px | **24 px** | |
| Тень панели | нет | **мягкая** `0 1px 2px rgba(16,24,32,.06)` | разделение без границ |

## 3. Компоненты чата

### Message
- Шапка: имя роли, время, бейдж модели (моноширинно, 11 px).
- Тело: 15/24, markdown, код в `bg/base` с радиусом 4.
- Под телом — `EvidenceStrip`: ссылки на tool-call, на которых основан вывод.
  Без evidence сообщение агента помечается бейджем `без обоснования` (янтарный).
- Сообщение агента с командой содержит `CommandChip`: тип, линия, значение и
  статус (`AWAITING_APPROVAL` → ссылка в пульт).

### Composer
Одна строка, 44 px, `Enter` — отправить, `Shift+Enter` — перенос. Слева —
переключатель роли (какой агент отвечает), справа — «приложить заказ».

### TraceTimeline
Для экрана трассы: вертикальная линия слева, шаги 32 px, каждый шаг —
иконка типа (`perceive`, `tool`, `propose`, `validation`, `approval`),
время в мс, длительность, стоимость в токенах. Отказы подсвечиваются
`status/danger` и содержат код (`INTERLOCK_001`).

### BudgetBar
Токены: израсходовано / лимит, полоса 4 px, при >80% — `status/warning`,
при исчерпании — бейдж `BUDGET_EXHAUSTED`, поле ввода блокируется.

## 4. Правила

- Агент никогда не «говорит» без метки роли и модели.
- Цитата данных — всегда с тегом и временем: `L2.Temp.PV = 87.4 °C (12:41:03)`.
- Сообщение системы (деградация, отказ API, `read-only`) — нейтральное, без пузыря.
- История не подгружается бесконечно: 50 сообщений + «показать раньше».
- `STALE`-значение в сообщении показывается с пометкой и временем.

## 5. Что нельзя

- Пузыри с градиентами и «хвостиками».
- Аватары-картинки вместо инициалов и роли.
- Скрывать, что ответ сгенерирован моделью.
- Показывать вывод агента как факт без evidence.
- Автопрокрутка, если пользователь читает выше (только кнопка «вниз»).
