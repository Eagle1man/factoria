## 6. Что проверить перед пилотом

1. Включить TLS в OPC UA и проверить отказ при неверном сертификате.
2. Заменить JWT в WS-строке на одноразовый тикет.
3. Включить лимит попыток входа и журналировать блокировки.
4. Провести проверку allowlist: команда на линию вне списка → отказ.
5. Прогнать сценарий «обрыв OPC UA» и убедиться, что UI не показывает
   последнее значение как текущее (тест есть — повторить на живом контуре).
6. Зафиксировать владельца OT-безопасности (OD-16).
