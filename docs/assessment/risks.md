## Что проверено, а что нет

**Проверено фактически:** установка стека на 3.14, паттерн method-нод
и отказ по interlock (`SPIKE_RESULT = PASS`), отсутствие Docker-демона,
неработоспособность зарегистрированных Python 3.11/3.13.

**Не проверено:** strict mode DeepSeek, `tool_choice + thinking`, реальная
пропускная способность WS на 21 теге, поведение LangGraph 1.x с `interrupt()`
при рестарте, совместимость 1С HTTP-сервисов (нет доступа).
