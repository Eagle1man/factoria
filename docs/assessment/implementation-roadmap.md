# IMPLEMENTATION-ROADMAP.md — уточнённый план

Дата: 2026-11-05. Основа: ТЗ §12, факты `technology-stack.md`, `risks.md`.
Оценки — в рабочих днях одного исполнителя с проверками (не «человеко-недели команды»).

## 1. Пересчёт оценок ТЗ

| Этап | ТЗ | Оценка здесь | Почему расходится |
|---|---|---|---|
| 0. Обследование | 1–2 нед. | **0,5 дня** | это чтение кода и документов, а не разработка |
| 0.5. Спайк DeepSeek | 0,5–1 день | **0,5 дня** | оценка верна, но заблокирована ключом |
| 1. Эмулятор | 1 нед. | **3–4 дня** | паттерн уже проверен спайком, остаётся 21 тег + 5 методов |
| 2. Backend | 2 нед. | **6–8 дней** | auth, registry, OPC UA-клиент, кэш, WS, SQLite, Alembic |
| 3. 3D + 2D | 1–2 нед. | **6–8 дней** | зависит от готовности Lovable-UI; 3D на примитивах — быстрее |
| 4a. Stub + валидатор 1–3 | 1 нед. | **4 дня** | идемпотентность и аудит уже спроектированы |
| 4b. HTTP-сервисы 1С | 2–3 нед. | **10–15 дней** | **блокирован**: нет версии, конфигурации и тестовой базы |
| 5. Агент sequential | 1–2 нед. | **5–7 дней** | после спайка DeepSeek; промпты надо написать с нуля |
| 6. Валидатор 4–5 + пульт | 2 нед. | **5–7 дней** | 28 ячеек матрицы + revalidate + TTL |
| 7. Supervisor + debate | 2 нед. | **5–7 дней** | чекпоинты LangGraph 1.x — главный источник сюрпризов |
| 8. Satisfactory | 2–3 нед. | **7–10 дней** | включать только после 7; версия игры/мода не проверена |

**Итого по критическому пути (без 4b и 8): ~5–6 недель.**
С 4b и 8: ~8–10 недель + ожидание доступа к 1С.
ТЗ пишет 20–25 недель — это оценка для команды с согласованиями; для одного
исполнителя без внешних задержек реальнее 8–10 недель, но с 4b почти наверняка
больше из-за доступа к 1С.

## 3. Что можно делать параллельно

- **4b** (BSL, расширение) не зависит от 5–7 — но требует доступа к 1С.
- **3** (3D/2D) не зависит от 4a/5 — нужен только backend этапа 2.
- **Документы** (`docs/api.md`, `docs/data-model.md`) уже написаны и не блокируют код.

## 4. Правила работы (из практики этого репозитория)

1. Один этап — один коммит, DoD проверяется запуском, а не описанием.
2. Результаты проверки писать в файл (`docs/assessment/checks/stageN.json`),
   потому что консольный вывод в PowerShell склонен к порче кодировки и
   обрезанию — уже наблюдалось в этом проекте.
3. Каждое отклонение от ТЗ — ADR в `docs/decisions.md`, а не молчаливое решение.
4. Публикация, `git push` и установка расширения в 1С — только человек.
5. `agent-1c-demo` не трогаем: любые эксперименты — в `factoria/`.

## 5. Что делать сразу после утверждения

1. Решить OD-01 (Python), OD-02 (порог 800), OD-07 (ключ DeepSeek).
2. Этап 1: `registry.yaml` + `emulator.py` + 5 методов + interlock-таймер
   `Load>95` → автостоп + генераторы `tag-registry.md` и `bindings.ts`.
3. Тест-набор: спайк из `scripts/spike_opcua_methods.py` превращается в pytest
   с маркером `integration`, чтобы регресс физики ловился сразу.
