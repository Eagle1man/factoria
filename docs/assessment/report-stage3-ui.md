## 4. ПРИЁМКА (формат `review.md`)

**Verdict:** экран делает свою работу — оператор видит три линии, уставки,
температуру, загрузку и качество данных без скролла; выглядит как пульт, а не
как лендинг; отрендерено на 1920/1280/1024 и дополнительно 390.

|---|---|---|---|
| P0 | `production` 1920 | `doc_width 1940` при `viewport 1920`: третий блок уезжал за экран, значения обрезаны | сетка `auto-fit minmax(340px,1fr)`, таблицы внутри `table-layout: fixed`, `min-width: 0` — стало 1920/1920 |
| P0 | `production` 1280 | третий блок вне экрана (часть страницы недоступна) | то же исправление; 1280 → 3 колонки по ~390 px |
| P0 | `production` 390 | `doc_width 771` при `viewport 390` | добавлен мобильный каркас ≤600 px: горизонтальный nav, стек, панели без min-width — 390/390 |
| P1 | `production` шапка | «seq 21 · 00:18:07» дублировало часы в topbar и мигало каждую секунду | оставлен только `seq`, время — в topbar |
| P2 | `production` таблица | одна и та же метка «обновлено 00:18:06» повторялась 7 раз в каждой линии, шум | время перенесено в подпись панели, в строках осталось только значение и единица |
| P2 | `production` значения | `STALE` отличался только цветом — нарушение «смысл не только цветом» | добавлен бейдж «устарело» рядом с названием параметра, значение окрашено в `--warning` |
| P3 | `production` 390 | блок `seq 21` переносится на вторую строку в заголовке | оставлено: не мешает |
| P3 | `production` кнопки | disabled-кнопки «Пуск/Стоп» визуально близки к активным | оставлено осознанно: `opacity .45` + `title` с причиной |

## 7. ПРОБЛЕМЫ

1. **Playwright не скачал Chromium** (ошибка загрузки). Обойдено системным
   Chrome: `channel="chrome"`. Зависимости нет, но на машине без Chrome
   скрипт потребует `playwright install chromium`.
2. **Дев-сервер Vite умирает между вызовами оболочки**, если запущен отдельной
   командой. Скриншоты снимаются в одном вызове со стартом сервисов.
3. **Заглушки — 6 маршрутов.** Это осознанно: выдуманных чисел нет, каждый
   экран говорит, на каком этапе появится.

## 8. РИСКИ

| ID | Риск |
|---|---|
| R-030 | Скриншоты снимаются через системный Chrome, версия на другой машине может отличаться — визуальная приёмка не воспроизводима побайтово |
| R-031 | Мобильная раскладка сделана «чтобы не ломалось», а не для работы оператора: по ТЗ минимальная ширина 1024 |
