## 4. КЛЮЧЕВОЕ ПРАВИЛО

Пустой ответ и недоступность источника **не выглядят одинаково**:

- `{"orders": []}` — валидный пустой список;
- `404` на `/orders/open` — ошибка конфигурации публикации, исключение;
- `500`, не-JSON, неверные поля — исключение `OnesUnavailable`.

Данные не подменяются заглушкой: если 1С недоступна, экран покажет ошибку,
а не демо-заказы.

## 8. СЛЕДУЮЩИЙ ШАГ

После публикации: `ONES_MODE=http` и `GET /api/v1/orders` должен вернуть
`"source": "http"`. Тогда закрывается 4b и появляется реальная связь
«заказ → линия» для двойника.

## 9. Скан базы DemoAgent (2026-11-07)

База была открыта в конфигураторе, поэтому выгрузка не выполнялась
(ошибка блокировки). Вместо этого выполнен read-only скан `1Cv8.1CD`.

Найдено: `Документ`, `Контрагенты`, `Номенклатура`, `Товар`,
`РеализацияТоваровУслуг`.

Не найдено: документа заказов. То есть **производственных заказов в базе нет**,
есть продажи. Это меняет смысл: «заказ» в API нельзя молча подменить продажей.

Решение за владельцем: (а) считать `РеализацияТоваровУслуг` заказом демо-контура
с явной пометкой, либо (б) добавить демо-документ заказа (изменение конфигурации).

## 11. Что удалось и что упёрлось (2026-11-07)

Удалось:

- полная резервная копия базы снята после закрытия конфигуратора;
- конфигурация выгружена в XML: `Catalogs\Контрагенты`, `Catalogs\Номенклатура`,
  `Documents\РеализацияТоваровУслуг`, язык `Русский`;
- метаданные документа: `Контрагент`, табличная часть `Товары`
  (`Номенклатура`, `Количество`, `Цена`).

Упёрлось:

- `C:\inetpub\wwwroot` требует прав администратора: создание папки и
  `webinst -deploy` отклонены (`PermissionDenied`);
- COM-коннектор не зарегистрирован: `V83.COMConnector` → `REGDB_E_CLASSNOTREG`;
  регистрация `comcntr.dll` тоже требует администратора.

Вывод: оба пути к реальной 1С требуют одного действия с правами администратора.
Код готов к обоим: `ONES_MODE=odata` (без правки конфигурации) и `ONES_MODE=http`
(HTTP-сервис в расширении).

## 12. Исправление команды публикации (2026-11-07)

Первая команда с `-deploy` была неверной: `webinstt.exe` ответил
«Неизвестный параметр командной строки: -deploy».

Справка утилиты: `webinst [-publish] websrv -wsdir VirtualDir -dir Dir
-connstr connStr [-confPath confPath] [-osauth]`, где `websrv` — это `-iis`
или `-apache2/22/24`. `-confPath` относится только к Apache.

Рабочая команда:

```
"C:\Program Files (x86)\1cv8t\8.3.27.1508\bin\webinstt.exe" -publish -iis ^
  -wsdir mfg -dir C:\inetpub\wwwroot\mfg ^
  -connstr "File=C:\1c_bases\DemoAgent;" -osauth
```
