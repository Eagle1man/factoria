# REPORT — ЭТАП 3, часть 3: 3D-сцена

Дата: 2026-11-06. Исполнитель: opencode (DeepSeek V4.1 Flash).

## 1. ЦЕЛЬ

Закрыть этап 3: 3D-сцена линий, где ротор вращается по `Speed.PV`, корпус
нагревается по `Temp.PV`, индикатор показывает работу, авария мигает, а при
`STALE`/`BAD` модель становится серой.

## 2. ЧТО СДЕЛАНО

| Файл | Что |
|---|---|
| `frontend\src\scene\LineModel.tsx` | модель линии: основание, корпус, ротор с валом и дисками, индикатор, HTML-метка |
| `frontend\src\pages\Scene.tsx` | Canvas, свет, сетка, OrbitControls, легенда, качество по линиям, проверка WebGL |
| `frontend\src\App.tsx` | маршрут `/scene` через `lazy()` — three.js грузится только на этом экране |
| `frontend\src\styles.css` | раскладка сцены и легенды, адаптив 1280/1024 |

## 3. ПРИВЯЗКИ (ADR-104)

Теги берутся из сгенерированного `frontend\src\scene\bindings.ts`, а не из
хардкода: `spin → Speed.PV`, `heat → Temp.PV`, `visibility → Running`,
`label → Load.Pct`. Если реестр изменится, сцена изменится вместе с ним.

## 5. ОГРАНИЧЕНИЯ

- Модель собрана из примитивов: GLB-ассета нет, это осознанно (OD-06).
- Вращение на скриншоте не видно; проверено кодом `useFrame` и тем, что
  положение ротора зависит от `Speed.PV`.
- Цвет «серый» проверен логикой `dead = quality !== 'GOOD'`; сценарий с
  реальным обрывом OPC UA на сцене не прогонялся (проверен на API).
- WebGL-фолбэк показывается текстом, но не проверен на машине без WebGL.

## 6. Модель станка v2 (2026-11-07)

Коробка заменена на процедурный токарный станок: станина с поддоном и
жёлто-чёрной полосой, передняя бабка, патрон с тремя кулачками и заготовкой,
задняя бабка с пинолью и маховиком, суппорт с резцедержкой, пульт с экраном
и кнопками, маячок, шланг СОЖ и кабель-канал.

Сцена: `Environment` с lightformers (без внешних HDR и CDN), контактная тень,
key/fill/rim свет, ACES-тонмаппинг, камера 42°.

Анимация: патрон и заготовка вращаются по `Speed.PV`, корпус светится при
нагреве выше 45 °C, маячок мигает при аварии, лёгкая вибрация при работе,
серая модель при `STALE`/`BAD`.

Проверено: сборка проходит, чанк сцены 924 КБ (+71 КБ), скриншоты
`scene_1920/1280/1024.png`, горизонтального скролла нет.

Референсы: `karisri/CNC-Simulator` (Three.js, G-code) — лицензия
«All rights reserved», код не копировался; `face-milling-surface-simulator`
(Vue + Three.js) — только идея композиции. Модель станка написана с нуля.
